## 2024-05-18 - Accessibility for Icon-Only Buttons\n**Learning:** In a vanilla HTML/JS app without a component library, dynamically generated UI elements (like cart items in script.js) often miss accessibility attributes because they are constructed via string interpolation. It is crucial to remember to add `aria-label` and `title` attributes not only to static HTML but also to these dynamically created elements.\n**Action:** Always check JavaScript files for dynamically generated HTML templates when auditing for accessibility issues like missing ARIA labels on icon-only buttons.
